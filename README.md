# Python Array Learning Game

## Descripción

Este es un juego interactivo en Python diseñado para ayudar a los estudiantes a aprender y verificar su comprensión de los métodos básicos de arrays (listas) en Python.

## Funciones que se evalúan

El juego evalúa el conocimiento de las siguientes funciones:

1. **len()** - Obtener la longitud del array
2. **sum()** - Sumar todos los elementos
3. **min()** - Encontrar el valor mínimo
4. **max()** - Encontrar el valor máximo
5. **index()** - Encontrar la posición de un elemento

## Características

- ✅ Preguntas aleatorias generadas dinámicamente
- ✅ Arrays aleatorios en cada partida
- ✅ Sistema de puntuación
- ✅ Retroalimentación inmediata
- ✅ Explicaciones de respuestas incorrectas
- ✅ Interfaz en español
- ✅ Ayuda integrada con ejemplos

## Requisitos

- Python 3.6 o superior
- No requiere librerías externas (solo usa módulos estándar)

## Cómo usar

### Opción 1: Ejecutar directamente
```bash
python3 python_array_game.py
```

### Opción 2: Dar permisos de ejecución (Linux/Mac)
```bash
chmod +x python_array_game.py
./python_array_game.py
```

## Estructura del juego

### Menú Principal
1. **Jugar** - Iniciar una nueva partida
2. **Ver ayuda** - Consultar información sobre las funciones
3. **Salir** - Cerrar el juego

### Flujo del juego
1. El juego presenta 5 preguntas (una por cada función)
2. Cada pregunta muestra un array aleatorio
3. El estudiante debe calcular la respuesta correcta
4. Se proporciona retroalimentación inmediata
5. Al final, se muestra la puntuación y evaluación

## Ejemplos de preguntas

### Pregunta len()
```
Array: [5, 12, 8, 3, 15, 9]
¿Cuál es la longitud del array? (usa len())
Tu respuesta: 6
✓ ¡Correcto! len() devuelve la cantidad de elementos.
```

### Pregunta sum()
```
Array: [4, 7, 2, 9]
¿Cuál es la suma de todos los elementos? (usa sum())
Tu respuesta: 22
✓ ¡Correcto! sum() suma todos los elementos del array.
```

### Pregunta min()
```
Array: [15, 3, 8, 12, 5]
¿Cuál es el valor mínimo del array? (usa min())
Tu respuesta: 3
✓ ¡Correcto! min() devuelve el elemento más pequeño.
```

### Pregunta max()
```
Array: [7, 19, 4, 15, 11]
¿Cuál es el valor máximo del array? (usa max())
Tu respuesta: 19
✓ ¡Correcto! max() devuelve el elemento más grande.
```

### Pregunta index()
```
Array: [10, 20, 30, 40, 50]
¿En qué posición (índice) se encuentra el valor 30?
(usa index() - recuerda que los índices empiezan en 0)
Tu respuesta: 2
✓ ¡Correcto! El índice de 30 es 2.
```

## Sistema de evaluación

- **100%**: ¡PERFECTO! Dominas completamente los arrays en Python
- **80-99%**: ¡Muy bien! Tienes un buen conocimiento de arrays
- **60-79%**: ¡Bien! Pero puedes mejorar con más práctica
- **0-59%**: Necesitas repasar más sobre arrays
